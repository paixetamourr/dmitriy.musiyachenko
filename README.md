# Портфолио Дмитрия Мусияченко

Статический сайт для существующего GitHub Pages. Сборка и npm не нужны.

## Локальный просмотр

Из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Не запускайте второй сервер, если порт уже занят.

## Файлы

- `index.html` — каркас, метаданные и подключения.
- `styles.css` — адаптивная вёрстка, темы и анимации.
- `app.js` — страницы, навигация, переключатели, галереи и типографика.
- `content.js` — тексты двух языков, структура кейсов и локальные изображения.
- `assets/design/` — SVG и адаптивные WebP из нового макета.
- `assets/fonts/` — локальные шрифты и сведения о лицензиях.
- `resume.pdf` — прежнее резюме; его можно заменить файлом с тем же именем.
- Прежние папки изображений сохранены для истории и возможного переиспользования.

Адреса страниц используют hash-маршруты, поэтому работают в подпапке GitHub Pages без настройки сервера. Старые ссылки на lumen, pulse4, olfactory-code, button, proto и posters также распознаются.

Строчные буквы сохранены как стилистический приём. В русских текстах короткие предлоги, союзы и частицы связываются со следующим словом неразрывным пробелом. Тексты внутри изображений остаются частью оригинального изображения.

## Проверка

Проверены девять страниц в Chromium на ширинах 320, 390, 768, 1440 и 1920 px; также выполнены проверки в WebKit. Проверены навигация, темы, язык, раскрытие этапов, карусель и просмотр плакатов и фотографий. Это браузерная проверка, а не испытание на каждом физическом устройстве.

Файлы подготовлены локально. Публикация на GitHub ещё не выполнена.
